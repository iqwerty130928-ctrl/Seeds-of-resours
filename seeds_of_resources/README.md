# Seeds of Resources

NeoForge 1.21.1 (Java 21).

Рецепт семени: в центре сетки 3x3 семя пшеницы, вокруг 8 штук ресурса.
Семя сажается на грядку, растёт как пшеница и при созревании даёт ресурс и семя.

Сейчас есть: уголь, железо, алмаз.
Сборка: `gradle build` -> `build/libs/seeds_of_resources-1.0.0.jar`
